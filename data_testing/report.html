필요한 전력량을 산출하는 방법
각 장비의 정격 전력(kW 또는 kVA)를 합산해서 병원 전체 소요 전력을 계산해요. 예: 초음파기 2kW + 내시경 세척기 3kW + 에어컨 10kW = 총 15kW 여기에 동시 사용률(동시 가동되는 비율)과 예비율(여유분)을 고려해서 최종 필요 전력을 잡습니다. ### 산출 공식 ``` 총 필요 전력 = Σ(장비 정격전력 × 동시사용률) × (1 + 예비율) ``` • 동시사용률: 보통 0.6~0.8 정도 적용 • 예비율: 보통 20~30% 확보 ### https://docs.google.com/spreadsheets/d/1qkMLaJmmuSYrzQIBMX5qYWjdfWs2QY4_LZCRKp2qxRI/edit?gid=0#gid=0
