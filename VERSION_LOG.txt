## v2.3.0 (2026-02-03)
### 변경사항: 보안 강화 및 버그 수정
- **검색 알고리즘 서버 이전**: 민감한 검색 로직을 /api/search.js로 이동
- **데이터 파일 서버 로드**: notionData.js, qaData.js를 서버에서만 로드 (프론트엔드 노출 차단)
- **채팅 기록 저장 버그 수정**: 구분선(---) 이후 내용이 잘리는 정규식 오류 수정

### 수정/추가 파일
- api/search.js: 검색 API 생성 (알고리즘 + 서버 데이터 로드)
- sheets-loader.js: 서버 API 호출로 변경, 데이터 전송 제거
- index.html: notionData.js, qaData.js 스크립트 제거
- chat-history.js: 구분선 정규식 버그 수정
