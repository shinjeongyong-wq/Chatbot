# 챗봇 버전 로그
===============================

## v2.4.0 (2026-02-03) - ❌ 롤백됨 (벡터 검색 실험 실패)
### 변경사항: 벡터 유사도 기반 검색 엔진 도입
- **Gemini Embeddings API 연동**: 문서/쿼리를 768차원 벡터로 변환
- **검색 스코어링 로직 단순화**: 기존 복잡한 보너스/페널티 → 3단계 곱셈 방식
  - 1단계: Base Score = (Vector × 0.7) + (Keyword × 0.3)
  - 2단계: Context Weight = Specialty × Intent
  - 3단계: Final Score = Base × Context
- **notionData.js 삭제**: 모든 데이터를 data/ 폴더에서 로드
- **구글 시트 데이터 통합**: Q&A(653개), FAQ(72개) → data/qa/ 폴더로 이동

### 수정/추가 파일
- generate-embeddings.js: 신규 - 문서 임베딩 생성 스크립트
- api/search.js: 새 스코어링 로직으로 완전 재작성
- data/**/*.json: 각 문서에 embedding 필드 추가
- sync-qa.js: 구글 시트 동기화 스크립트
